# Assignment 2

This project contains the required exercises from Lab 5.
The work includes creating processes with `fork()`,
linking multiple C files, using a loader, and building programs with a Makefile.

## Installation

To build all programs, run:
```bash
make

This will create the executables:

fork

output_program

simple_p
```
## Usage

To run the programs:

./fork
./output_program
./simple_p

## Project Files

fork.c — program that uses fork().

file1.c and file2.c — linker example.

simple_p.c — loader example.

Makefile — builds all programs.

answers.txt — written answers.

## Requirements

Linux or WSL

gcc

make
